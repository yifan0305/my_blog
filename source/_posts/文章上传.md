## 第一步: 写(本地)  

在终端输入 `npx hexo new post "文章标题"`, 然后在 VS Code 里写 Markdown 和公式.  
写完后, 用 `npx hexo server` 本地预览一下.

## 第二步: 发(公网)

本地看着满意了, 终端敲一句: `npx hexo g -d`.  

## 第三步: 存(备份源码)

为了不让文章和配置因为电脑坏了而丢失, 把源代码推送到 main 分支:  

```cmd
git add .
git commit -m "feat: add new post about xxx"
git push
```
